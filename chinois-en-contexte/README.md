# 语境中文 · Le chinois en contexte

B1–B2 中国当代社会与文化课程。课程短文为原创教学材料，外部链接用于延伸阅读或观看。

## 新增课程

1. 打开 `lessons.js`，在数组末尾复制上一课对象。
2. 改为唯一课号，例如 `C25`，并填写中法标题、学习目标、短文、词汇（中文／拼音／法语）、语块、句型、素材链接、讨论和口语任务。现有主题使用同一个 `topic`，新主题会自动加入筛选。
3. 双击 `index.html` 预览，检查新课和筛选。提交到主站仓库的 `main` 后，GitHub Pages 自动发布。可用 `#C25` 直接分享该课。

入口为 `index.html`，样式为 `style.css`，浏览与跳转逻辑为 `app.js`。新增普通课程只需修改 `lessons.js`。
