# 语境中文 · Le chinois en contexte

面向所有 B1–B2 学习者的中国当代社会与文化专题库。各专题可独立学习，也可按主题浏览。

## 新增专题

1. 在 `lessons.js` 的数组末尾复制一个现有专题，填写中法标题、学习目标、短文、词汇、语块、句型、讨论和口语任务。没有延伸素材时，`media` 填 `[]`。
2. 为 `slug` 填写唯一的小写链接名，例如 `vie-de-quartier`。沿用已有 `topic` 可以加入对应筛选，新主题会自动出现。
3. 双击 `index.html` 预览，检查专题和筛选。提交到主站仓库的 `main` 后，GitHub Pages 自动发布。可用 `#vie-de-quartier` 直接分享专题。

入口为 `index.html`，样式为 `style.css`，筛选与跳转逻辑为 `app.js`。
